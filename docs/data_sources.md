# Archimedes data-source registry

The master list of every high-quality open resource we pull, per lobe. The rule
is **curated, licensed, high-signal** — not raw web crawling. Raw web is ~90%
noise; the value is in the filtering, and for the sources below that filtering
is already done. Two data tracks feed every lobe:

- **Pretraining corpus** (fluency + format) — the sources in this file, pulled
  via `retrieve.py` → `curate_<domain>.py` → tokenizer → `build_token_shards.py`.
- **Synthetic verified curriculum** (the actual *skill*) — generated by
  `build_<domain>_curriculum.py`, unlimited and 100% verifiable. This is where
  the efficiency edge comes from; pretraining only gives fluency.

Empirically (math, physics): the skill came from the curriculum, not the
corpus. So the corpus target per lobe is "enough" (~25–40M tokens), and effort
scales the **curriculum breadth**, not the crawl size.

---

## Pull pipeline (same for every lobe)

```
retrieve.py            # download raw docs from a *_sources.yaml
ingest_arxiv_papers.py # full-text PDFs from a *_arxiv_bulk.yaml metadata pull
curate_<domain>.py     # dedup + quality-gate + topic-tag -> train/val manifest
train_tokenizer.py --split-digits   # digit-split tokenizer (the durable fix)
build_token_shards.py  # -> shards/<domain>_tokens_v1
```

## Standing open corpora (use, don't re-scrape)
When a lobe needs bulk fluency text, draw from these already-filtered sets
rather than crawling from scratch:
- **FineWeb-Edu** (1.3T tok, quality-classified web) — subset per domain
- **Dolma**, **RedPajama-v2** — open pretraining mixes
- **The Stack v2** — code
- **PeS2o / S2ORC** — open academic full text
- **Wikipedia / Wikibooks / Wikisource** dumps — CC-BY-SA
- **Project Gutenberg** — public-domain books

## Provenance rule
Every doc lands in `documents.sqlite` with `source_name`, `source_url`,
`license`, `source_type`. Licenses are recorded per record; verify before any
redistribution or training-set release. arXiv paper licenses vary — metadata is
open, full text is per-record.
